# Digest quality rubric (applies to any item that changes digest output)

1. Short: the whole daily digest reads in under 2 minutes.
2. Calm and fun: friendly, lightly opinionated voice; zero clickbait phrasing, zero engagement-bait.
3. Useful ordering: yesterday's results -> today's matches (IST kickoff times) -> what to watch.
4. Honest about gaps: missing data shows as "data unavailable", never invented.
5. Renders correctly in both markdown (CLI) and HTML (web) without surface-specific hacks in core.
